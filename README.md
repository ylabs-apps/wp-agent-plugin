# WP Agent — Manage WordPress from Chat

Run your self-hosted WordPress site from Claude: write and publish posts, edit pages, upload media, moderate comments, update menus, check SEO and manage plugins. Connect with just your site URL. No AI key needed.

## Use it

1. Install the plugin, then connect WP Agent using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Publish my latest draft on my WordPress site tomorrow at 9am and add it to the main menu."
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.getwpagent.com/mcp. Tool requests are handled by WP Agent (https://www.getwpagent.com/privacy/). This bundle contains no separate storage service.
